# Plan de evidencia externa

Exacta7 no debe fabricar reseñas, afiliaciones ni testimonios. La prioridad es obtener evidencia verificable y útil para profesionales.

## Propuestas

1. **Docentes y facultades de Veterinaria**: invitar a evaluar el uso de fórmulas visibles y fuentes regulatorias en actividades docentes; publicar solo una mención o caso con consentimiento y atribución verificable.
2. **Veterinarios y clínicas**: recoger experiencias de uso con función concreta, contexto, fecha, profesión y consentimiento; no pedir afirmaciones de eficacia clínica que no puedan verificarse.
3. **Asociaciones y medios especializados**: proponer una nota metodológica sobre separación entre datos regulatorios, evidencia clínica y cálculo, no una campaña de enlaces masivos.
4. **Comunidades VetTech**: solicitar listados o demostraciones cuando el organizador pueda revisar el producto de forma independiente.

## Formato futuro de una opinión verificable

- nombre;
- profesión;
- organización, si procede;
- contexto y función usada;
- comentario literal;
- fecha;
- URL o fuente verificable;
- consentimiento de publicación.

No añadir `Review` schema ni testimonios hasta disponer de evidencia real.

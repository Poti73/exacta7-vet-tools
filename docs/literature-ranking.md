# Ranking bibliográfico

El ranking es determinista y explicable: tipo de publicación, coincidencia de indicación en título, coincidencia de especie, abstract disponible y actualidad acotada. La jerarquía ordena guías, consenso, revisiones sistemáticas, meta-análisis, ensayos y estudios observacionales; no recomienda medicamentos.

Publicaciones con el tipo `Retracted Publication` se excluyen de los destacados. Las correcciones se almacenan como estado de metadata cuando el proveedor las aporte. Cada tarjeta indica metadatos coincidentes en “Por qué aparece”.

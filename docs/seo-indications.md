# SEO de indicaciones

Las entidades usan slug canónico y aliases. Las páginas `/indicaciones/*` están deliberadamente `noindex` hasta que aporten datos regulatorios o literatura cacheada con valor suficiente. No se incluyen en sitemap por ahora.

No se indexan búsquedas internas, filtros, parámetros ni combinaciones de especie sin contenido verificable. Cuando una entidad tenga contenido aprobado se añadirá title, description, canonical, hreflang, breadcrumbs y sitemap desde una única URL canónica.

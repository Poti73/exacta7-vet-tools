# Investigación UX del módulo

Consulta 2026-09-16. Se revisan páginas públicas, no se afirma haber probado cuentas, móviles físicos, paywalls ni flujos protegidos.

- MDCalc (https://www.mdcalc.com/): búsqueda destacada por calculadora/especialidad/condición y catálogo por áreas. Aplicado: entrada por nombre o contexto y agrupación por tipo.
- InfusionFox (https://infusionfox.com/): herramienta profesional con fuentes y cálculo. Aplicado: visibilidad de límites de uso y separación entre selección y operación.
- VetCalculators: el sitio directo devolvió 403; ficha del editor en App Store enumera CRI, dosis, fluidos y referencias. No se ha podido evaluar la interacción real; no se extrapolan resultados de accesibilidad.
- Dechra: documento oficial de cálculo de infusión (https://www.dechra-us.com/Files/Files/SupportMaterialDownloads/us/US-072-POS.pdf). Referencia de presentación de unidades; no se copian tasas ni tablas.
- MSD calculators, ServetUrgencias y AVA: las rutas consultadas no se pudieron recuperar. Pendiente de evaluación; no se inventan hallazgos.
- 21st: búsqueda de metadatos “accessible grouped command search”; Command (originui, 382) y Search Tool (serafimcloud, 12366). No se descargó código de pago. Se implementa componente original con enlaces semánticos y acciones separadas.

Decisiones propias: encabezado con buscador en desktop y fila prominente completa en móvil; Ctrl/Cmd+K, flechas, Enter, Escape, Tab y touch; estados vacíos; coincidencias aproximadas identificadas; paciente visible; cinco secciones estables de ficha; acciones de cálculo sin dosis preseleccionada.

# Modelo de evidencia

Las capas no son equivalentes: A) datos regulatorios AEMPS, B) literatura relacionada recuperada automáticamente y C) recomendaciones clínicas revisadas.

`ReviewedRecommendation` soporta el flujo `draft → review_required → reviewed → approved → published → updated → retired`. La colección publicada está vacía deliberadamente: ningún proveedor bibliográfico puede rellenarla.

La taxonomía de indicaciones guarda aliases, especie, URL canónica y fechas de comprobación. No contiene afirmaciones terapéuticas ni rangos de dosis.
